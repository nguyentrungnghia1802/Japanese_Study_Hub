## Regression fixed during verification

The Web client initially sent dictionary favorite attribution as a nested
`source` object, while the authenticated API DTO intentionally validates flat
`sourceProvider`, `sourceName`, `sourceUrl`, `sourceLicense`, and
`sourceAttribution` fields. The API returned `Validation failed`. The client
now maps the public contract to the validated wire payload in commit
`839ae7b`, and the save/remove browser journey passed afterward.

The provider sanitizer boundary was also consolidated for CommonJS/Vite
interop in commit `be99c31`; API lint, build, and focused provider tests passed
after the change.
